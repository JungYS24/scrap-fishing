# 스크랩 피싱 가챠 적용안

2026-10-22 · 정윤성

## 개요

판에서 번 달러를 쓰는 **암시장 오리파**(가챠)를 추가한다. 플레이어는 루어·보트·드론·수트 머신 중 하나를 골라 달러로 뽑고, 연출을 본 뒤 결과를 받는다. 필요 없는 장비는 달러로 환원(원가보다 낮게)하고, 쓸 장비는 보관함에서 **적용**을 눌러 실제 낚시와 잠수에 반영한다.

- 목적: 중간 피드백의 "성장이 빨리 끝남", "재화 쓸 곳 없음"을 해결하고, 보류였던 가챠를 게임 루프에 넣는다.
- 범위: 머신 4종, 1회·10연 뽑기, 연출, 결과·환원, 보관함·적용, 천장(보장) 시스템.
- 제외: 실제 현금 결제 없음. 모든 재화는 게임 안의 달러뿐이다.
- 기존 원칙 유지: 한 판 60초, 강화 3종(릴/보트/수심, 최대 12레벨), 등급 4단계와 등급 색.

## 컨셉과 레퍼런스

화면 구조와 흐름은 클로브 오리파를 그대로 따르고, 겉모습만 2091년 우버클래스 암시장으로 바꾼다. 흰 바탕 카드 UI 대신 다크 블루 바탕에 네온 그린·마젠타 테두리를 쓰고, 오미쿠지 소녀 대신 크레인이 폐기물 컨테이너를 끌어올리는 연출을 쓴다.

| 클로브 요소 | 스크랩 피싱 대응 |
| --- | --- |
| 상단 바: 로고, JP, 포인트 잔액, 알림 | 상단 바: "BLACK MARKET" 로고, 달러 잔액, 닫기(출항 화면으로) |
| 카테고리 탭: 전체/포켓몬/원피스/하비 | 머신 탭: 전체/루어/보트/드론/수트 |
| 머신 카드: 배너, 태그(신규·이벤트·최소 보장), 1회 가격, 진행 게이지 | 머신 카드: 배너, 태그(신규·천장 임박·확정 레어), 1회 가격, 천장 게이지 |
| 총 환원율 98% 표기 | 총 환원율 약 75% 표기(등급별 환원가 기준 기댓값) |
| 1회·10연속·100연속·1,000연속 버튼 | 1회·10연 버튼(100연·1,000연은 제외) |
| 확인 팝업: 안내 문구, 잔액 전→후, "25pt로 뽑기"/취소 | 확인 팝업: 확률·환원 안내, 달러 전→후, "$N로 뽑기"/취소 |
| 오미쿠지 연출 + Lv.1~6 색 범례 + 건너뛰기 | 크레인 인양 연출 + 등급 4색 범례 + 건너뛰기 |
| 뽑기 결과: 등급별 묶음, 합계, 체크박스, 전체 선택/초기화 | 같은 구조, 하단 버튼만 "달러 환원" / "보관함으로" |
| 포인트 환원 확인 → 환원 완료 + 다시 뽑기 | 달러 환원 확인 → 환원 완료 + 다시 뽑기 |
| 획득 상품: 미선택/대기/발송됨 | 보관함: 미처리/보관 중/장착 중 |
| 당첨 내역 | 최근 뽑기 기록(최근 50건) |

## 가챠 카테고리

머신은 장착 슬롯과 1:1로 대응하는 4종이다. 각 머신은 등급마다 1~2개씩, 머신당 6개 안팎의 장비를 담는다. 아래는 등급별 대표 예시이고, 수치는 밸런스 단계에서 조정한다.

| 머신 | 등급 | 장비 예시 | 게임 효과 |
| --- | --- | --- | --- |
| 루어 | Normal | 녹슨 자석 루어 | 루어 용량 +1 |
| 루어 | Rare | 네온 미끼 루어 | 루어 용량 +2, 흡착 반경 +10% |
| 루어 | Epic | 드론 코어 루어 | 루어 용량 +3, 레어 이상 출현 +5% |
| 루어 | Legend | 크라켄 촉수 루어 | 루어 용량 +4, 레어 이상 출현 +12% |
| 보트 | Normal | 덧댄 철판 바지선 | 판매가 +3% |
| 보트 | Rare | 네온 간판 바지선 | 판매가 +6%, 수심 게이지 속도 -10% |
| 보트 | Epic | 신젠 폐선 개조선 | 판매가 +10%, 수심 게이지 속도 -15% |
| 보트 | Legend | 메카 잔해 요새선 | 판매가 +18%, 판 종료 보너스 $ +10% |
| 드론 | Normal | 구형 감시 드론 | 잠수 중 자동 흡착 반경 +10% |
| 드론 | Rare | 수색 드론 | 흡착 반경 +20%, 위험물 사전 경고 |
| 드론 | Epic | 회수 드론 | 흡착 반경 +30%, 10초마다 근처 스크랩 1개 회수 |
| 드론 | Legend | 프로토타입 AI 드론 | 흡착 반경 +40%, 6초마다 회수, 위험물 1회 방어 |
| 수트 | Normal | 방수 우비 | 산소 +10% |
| 수트 | Rare | 침식 방지 코팅 | 산소 +20%, 위험물 피해 -25% |
| 수트 | Epic | 사이버 잠수복 | 산소 +30%, 위험물 피해 -50% |
| 수트 | Legend | 심연 엑소슈트 | 산소 +45%, 위험물 피해 무효 |

- 효과 종류는 기존 시스템(루어 용량, 판매가, 산소, 위험물, 흡착)에 붙일 수 있는 것만 고른다. 새 기믹은 드론의 자동 회수 하나뿐이다.
- 판 시간(60초)을 늘리는 효과는 넣지 않는다. 한 판 1분 원칙을 지키기 위해서다.
- 이름은 README의 수심대별 수집품과 세계관 용어를 재사용해 톤을 맞춘다.

## 화면 구성

화면은 7개이고, 모두 480×854 세로 기준으로 런타임에 코드로 생성한다(씬 파일 수정 없음). 진입점은 타이틀 화면과 결과 화면의 "암시장" 버튼 두 곳이다.

| 화면 | 클로브 참고 | 구성 요소 |
| --- | --- | --- |
| 머신 목록 | 오리파 메인 | 상단 달러 잔액, 머신 탭, 머신 카드 세로 스크롤, 하단 탭(머신/보관함/기록) |
| 뽑기 확인 팝업 | 25pt로 뽑기 팝업 | 배너, 안내 4줄(환원가·환원율·천장·확률), 달러 전→후, 뽑기/취소 |
| 연출 | 오미쿠지 화면 | 크레인 인양 애니메이션, 우측 등급 색 범례, 사운드 토글, 건너뛰기 |
| 뽑기 결과 | 뽑기 결과 | 등급별 묶음(높은 등급 먼저), 등급별 합계 $, 카드마다 체크박스, 전체 선택/초기화, 선택 합계 $, 달러 환원/보관함으로 |
| 환원 확인 | 포인트 환원합니다 | 선택 개수, 달러 전→후(초록), 확정하기/취소 |
| 환원 완료 | 포인트로 교환했어요 | 체크 아이콘, 달러 전→후, 같은 머신 "다시 뽑기" 카드 |
| 보관함 | 획득 상품 | 미처리/보관 중/장착 중 탭, 슬롯별 장착 칸 4개, 카드마다 적용·환원 버튼 |

- 결과 화면을 건너뛰거나 닫으면 선택하지 않은 장비는 "미처리"로 보관함에 남는다. 달러가 사라지는 일은 없다.
- 등급 표시는 기존 색을 그대로 쓴다: Rare #3FA9FF, Epic #B45CFF, Legend #FF9A2E. Normal은 회색 테두리다.
- 클로브의 "시장 시세와 일치를 보장하지 않습니다" 문구 자리에는 "표시된 확률은 이 배너 기준이며, 천장 보정이 적용되면 레전드 확률이 올라갑니다"를 넣는다(데일리는 "레어 이상 확정", 축제는 "30회째 레전드 이상 확정").

## 뽑기 흐름과 연출

한 번의 뽑기는 "머신 선택 → 확인 → 연출 → 결과 → 환원 또는 보관 → 적용" 순서로 진행된다. 결과는 확인 버튼을 누르는 순간 확정하고 저장하므로, 연출 도중 앱을 꺼도 결과는 보관함에 남는다.

1. 배너 카드에서 1회·10연 중 하나를 누른다.
2. 확인 팝업에서 달러 전→후를 보고 뽑기를 누른다. 잔액이 모자라면 버튼이 회색이 되고 "출항해서 벌어 오기" 안내가 뜬다.
3. 결과를 즉시 계산해 저장한 뒤 연출을 시작한다.
4. 연출이 끝나거나 건너뛰기를 누르면 결과 화면으로 간다.
5. 결과 화면에서 장비를 골라 달러로 환원하거나 보관함으로 보낸다.
    - 환원: 환원 확인 → 환원 완료 → 다시 뽑기 또는 닫기
    - 보관: 보관함 "보관 중" 탭으로 이동
6. 보관함에서 적용을 누르면 해당 슬롯에 장착되고, 다음 출항부터 효과가 반영된다.

**연출 단계(1회 기준, 약 3초, DOTween)**

1. 수면 아래에서 크레인 와이어가 내려간다(0.6초).
2. 컨테이너를 끌어올리며 화면이 흔들린다(0.8초).
3. 컨테이너 틈으로 빛이 새고, 빛 색이 등급 색으로 바뀐다(0.8초). Epic 이상은 색이 한 단계씩 올라가는 "승격" 연출을 넣는다.
4. 컨테이너가 열리며 장비 카드가 튀어나온다(0.8초). Legend는 화면 플래시와 legend_appear 효과음을 쓴다.

- 10연은 이번 묶음의 최고 등급 하나만 연출하고, 나머지는 결과 화면에서 카드가 순서대로 뒤집히는 방식으로 보여 준다.
- 우측 범례는 클로브의 Lv.1~6처럼 등급 4색을 세로로 표시하고, 현재 빛 색에 해당하는 칸을 강조한다.
- 효과음은 기존 SoundCue 구조를 쓴다. 새 키 후보: gacha_drop, gacha_lift, gacha_glow, gacha_open. 파일이 없으면 fallback으로 재생된다.

## 등급, 확률, 가격, 환원

1회 가격을 P라 할 때 환원 기댓값은 약 0.75P로, 머신 카드에 "총 환원율 약 75%"로 표기한다. 등급 판정은 반드시 ItemData.Rarity를 쓴다(ScrapGrade의 Mutant 통합 판정은 쓰지 않음).

| 등급 | 확률 | 환원가 | 기댓값 기여 |
| --- | --- | --- | --- |
| Normal | 70% | 0.3P | 0.21P |
| Rare | 22% | 0.8P | 0.176P |
| Epic | 7% | 3P | 0.21P |
| Legend | 1% | 15P | 0.15P |

| 뽑기 | 가격 | 보장 |
| --- | --- | --- |
| 1회 | P | 없음 |
| 10연 | 10P | Rare 이상 1개 확정 |

- 천장: 머신별로 Legend 없이 100회를 뽑으면 다음 1회는 Legend 확정이다. 머신 카드의 게이지가 이 진행도를 보여 준다(클로브의 남은 수량 게이지 자리).
- 중복: 같은 장비를 또 뽑으면 결과 카드에 "보유 중" 표시를 붙이고 환원을 기본 선택으로 둔다. 중복 강화(+1, +2)는 2차 범위로 미룬다.
- P 기준값: 평균적인 1판 수익의 약 1/3로 잡는다. 실제 숫자는 현재 강화 비용(기본가 × 1.38^레벨)과 판당 평균 달러를 로그로 확인한 뒤 정한다.
- 머신마다 P를 다르게 둘 수 있다. 예: 루어·수트 1P, 보트·드론 1.5P.

## 적용(장착)과 게임 반영

슬롯은 루어·보트·드론·수트 4칸이고 칸마다 장비 1개만 장착한다. 장착 효과는 기존 강화 효과 위에 더하는 방식이며, 다음 출항부터 반영된다.

| 슬롯 | 반영 지점(기존 스크립트) | 화면에서 보이는 변화 |
| --- | --- | --- |
| 루어 | RodStats, LureLoad, ScrapSpawner(스폰 수 = 용량+2 규칙 유지) | 루어 스프라이트 색, HUD 용량 숫자 |
| 보트 | RunSession·결과 정산, DepthGauge | 보트 스프라이트 색·장식, 결과 화면 "보트 보너스 +$" 줄 |
| 드론 | DiveDirector, MagnetPickup, Hazard | 잠수 중 다이버를 따라다니는 드론, 회수 시 빔 이펙트 |
| 수트 | OxygenMeter, Hazard | 다이버 색, 산소 게이지 길이 |

- 적용을 누르면 기존 장착품은 "보관 중"으로 돌아간다. 장착 중인 장비는 환원할 수 없다.
- 출항 전 화면(보트 HUD) 한쪽에 장착 슬롯 4칸을 아이콘으로 작게 보여 준다. 플레이어가 효과를 체감하게 하려는 장치다.
- 결과 화면의 "다음 목표" 문구에 "암시장 1회까지 $N"을 추가해, 판 수익과 가챠를 연결한다.
- 위 반영 지점은 파일 이름 기준 추정이다. 구현 전에 각 스크립트의 실제 계산 위치를 확인해야 한다.

## 구현 설계

로직과 UI를 나눠, 확률·천장·환원 계산은 UI 없이 테스트할 수 있게 만든다. 새 스크립트는 Assets/Scripts/Gacha 폴더에 모은다.

| 구분 | 이름 | 역할 |
| --- | --- | --- |
| 데이터 | GearData (ScriptableObject) | id, 슬롯, 등급(ItemData.Rarity), 효과 종류·수치, 환원가 배수, 스프라이트 |
| 데이터 | GachaMachineData (ScriptableObject) | 슬롯, 1회 가격 P, 등급별 확률, 장비 목록, 천장 횟수, 배너 |
| 로직 | GachaService | 뽑기 계산, 10연 보장, 천장 카운트. 난수는 주입해 테스트 가능하게 |
| 로직 | GearInventory | 보유 목록, 상태(미처리/보관/장착), 환원 처리 |
| 로직 | GearBonuses | 장착 장비 효과를 합산해 RodStats·OxygenMeter 등에 제공 |
| UI | GachaShopView, GachaConfirmPopup, GachaRevealView, GachaResultView, GearInventoryView | 런타임 생성 UI. 기존 UiButton, CountingText, ChipFlyFx 재사용 |
| 테스트 | Tests/Editor/GachaServiceTests | 확률 분포(1만 회), 10연 보장, 천장, 환원 금액 |

- 저장: 보유 장비, 장착 상태, 머신별 천장 카운트, 최근 기록 50건을 기존 저장 데이터에 추가한다. SaveVersion을 3으로 올리되, 이번에는 초기화하지 않고 기존 달러와 강화 레벨을 그대로 옮기는 마이그레이션을 넣는다.

## 작업 순서와 리스크

로직 → 결과·환원 → 적용 → 연출 순서로, 단계마다 커밋 1개씩 나눈다. 연출이 늦어져도 3단계까지만 끝나면 "재화 쓸 곳" 피드백 반영으로 발표에 쓸 수 있다.

1. 데이터·GachaService·GearInventory·저장 마이그레이션 + EditMode 테스트
2. 머신 목록, 확인 팝업, 결과 화면, 환원 확인·완료(연출 없이 바로 결과)
3. 보관함, 적용, GearBonuses를 게임에 연결, 보트 HUD 슬롯 표시
4. 크레인 연출, 등급 범례, 효과음 키 추가
5. 밸런스 조정(P 값, 효과 수치), 가능하면 DEV 패널에 확률·P 슬라이더 추가

**발표 활용**

- 5장 피드백 반영: "재화 쓸 곳 없음" → 전(10/14 빌드 결과 화면) / 후(암시장 화면) 캡처.
- 4장 게임 흐름: 결과 화면 → 암시장 → 재출항으로 루프가 하나 늘어난 것을 보여 준다.

**리스크**

- 밸런스: Legend 장비가 너무 강하면 강화 12레벨이 의미 없어진다. 가챠 효과 합계가 강화 최대치의 절반을 넘지 않게 상한을 둔다.
- 세션 길이: 가챠 화면에 오래 머물러도 "한 판 1분"은 출항 기준이라 조건에는 영향이 없다. 발표 때 이 점을 설명한다.
- 저장 데이터: 마이그레이션 실패 시 달러가 사라질 수 있다. 실패하면 기존 데이터를 그대로 두고 가챠 데이터만 새로 만든다.
- 오해 소지: 실제 결제가 없는 게임 내 재화 시스템임을 머신 목록 상단 안내에 명시한다.
- 일정: 최종 발표 전 재빌드·배포가 우선이다. 가챠 작업이 길어지면 배포를 먼저 하고 가챠는 다음 배포로 넘긴다.

## 결정 사항 (2026-10-22, 1단계 반영)

- 1회 가격 P: 루어·수트 $5,000, 보트·드론 $7,500.
- 천장(확정 당첨)은 없다. 대신 머신별로 Legend 없이 뽑은 횟수를 세고, 주기 101회 안에서 51번째 뽑기부터 Legend 확률을 1% → 5%(101번째)로 선형 보간해 올린다. Legend가 나오거나 101회가 지나면 카운트를 0으로 되돌린다. 수치는 GachaMachineData의 boostCycle/boostStart/boostLegendRate로 조정한다.
- 보간을 넣으면 장기 평균 Legend 확률과 환원율이 표 값보다 조금 높아진다. 실제 값은 GachaService.EffectiveRates / ExpectedRefundRate로 계산해 표기한다.
- 보관함은 장비 id별 개수(미처리/보관 중)로 묶어 저장하고, 장착품은 슬롯마다 1개를 따로 저장한다. 보관함 화면은 카테고리(슬롯)별로 거를 수 있다.
- 저장: PlayerPrefs 키 "GachaSave"(JSON) 하나에 보유 장비, 장착, 머신별 카운트, 최근 기록 50건을 넣는다. SaveVersion 2 → 3은 달러·강화를 그대로 두고, 2 미만은 기존 규칙대로 초기화한다.

## 배너 26종 (2026-10-26)

100연은 없앴다. 모든 배너는 1연·10연(데일리는 1연만)이고, 10연은 레어 이상 1개를 보장한다. 배너 데이터는 `Resources/Gacha/oripa_banners.json`(사본 `planning/oripa_banners.json`)에 있고, 장비·등급·환원 배율은 `oripa_rewards.json`을 그대로 쓴다. 26개 모두 상시 노출이며, 로테이션 필드(`rotation`)는 읽기만 하고 아직 쓰지 않는다.

| 종류 | 수 | 풀 | 1회 가격 | 등급 확률 | 천장 |
| --- | --- | --- | --- | --- | --- |
| 상시(standard) | 6 | 해당 머신 15종 | 머신 가격(기본 $5,000 × pricePerPull) | 머신 그대로 | 머신 카운터(51회째부터 Legend 상승) |
| 레전드 픽업(pickup legend) | 12 | 해당 머신 15종 | 머신 가격 | 상시와 같음. 레전드가 나오면 75% 픽업, 25% 다른 레전드(픽업 1.2%, 다른 레전드 0.4%) | 머신 카운터 공유. 보정 중에도 75:25 유지 |
| 싱크로 픽업(pickup synchro) | 6 | 해당 머신 15종 | $10,000 | 노멀 70%, 레어 21%, 에픽 7%, 레전드 1.2%, 싱크로 0.8%(싱크로는 항상 픽업, 레전드 2종 반반) | 머신 카운터 공유. 보정은 레전드만 올리고 싱크로 0.8%는 고정 |

- 상시 배너는 JSON의 `price`를 쓰지 않고 머신 가격(`basePrice × pricePerPull`)을 쓴다. 상시 머신의 확률·가격·천장이 배너 파일 때문에 바뀌지 않게 하기 위해서다.
- 환원 금액은 배너 가격이 아니라 "등급 환원 배율 × 그 장비 머신의 1회 가격"이다. 그래서 싱크로 픽업($10,000)의 기대 환원율은 약 42%(루어·낚싯대·헬멧) ~ 64%(보트·드론·피셔)다.
- 데일리 날짜는 기기 시간대와 상관없이 KST(UTC+9) 05:00 기준이다. 마지막으로 받은 날짜만 저장하므로 기기 시계를 돌리는 것은 막지 않는다.
- 축제는 남은 횟수가 10 미만이면 10연 버튼만, 0이면 1연도 비활성화하고 "완료"를 표시한다. 배너 자체는 계속 보인다.
- 연출 영상: 상시·픽업은 그 머신 영상, 데일리·축제는 이번 결과에서 가장 높은 등급 장비(같으면 첫 번째)의 머신 영상.
- 화면: 전체 탭은 대축제 → 오늘의 암시장 → 상시 6종 → 픽업 18종, 머신 탭은 그 머신의 상시 1 + 픽업 3. 카드는 처음 한 번 만들고 탭을 바꿀 때는 켜고 끄며 값만 갱신한다. 배너 전용 아트는 `bannerImage`(Resources 경로) 필드를 넣으면 쓴다.
- 저장 키(배너 id가 뒤에 붙음): `GachaDailyDay_`(마지막 수령 KST 날짜), `GachaFestivalPulls_`(축제 누적 횟수), `GachaFestivalHigh_`(축제 레전드 이상 획득 여부). 뽑기 기록은 `machine`에 장비의 머신 id, `banner`에 배너 id를 남긴다(배너 이전 기록은 `banner` 없음).

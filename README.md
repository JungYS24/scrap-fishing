# 🎣 Scrap Fishing

> 오염된 우버클래스(灣)에서, 낚싯대 하나로 하루를 버티는 노마드 해체업자의 이야기.

캐주얼 아케이드 피싱 + 성장형 하이브리드 웹게임 — 모바일 브라우저에서 QR 스캔 한 번으로 바로 플레이.

## 🌆 세계관

**서기 2091년.** 신젠 코퍼레이션의 무분별한 개발과 방사능·나노 폐기물로 침식된 **우버클래스(Uber Class)**.
화려한 네온사인 고층 빌딩 아래로, 썩어가는 녹색·보라색 발광 해수와 부유 쓰레기 더미가 펼쳐진다.

플레이어는 부유선(Barge) 하나에 의지해 떠도는 **해체업자 노마드**. 사이버네틱 의수와 개조된 크레인 낚싯대로 수중 폐품과 변이 생명체를 건져 올려 암시장에 팔아 하루하루 연명한다.

- **컬러 팔레트**: 네온 그린 / 마젠타 / 다크 블루
- **톤앤매너**: 사이버펑크 브라운관 · VHS 글리치 · 로우파이 신스웨이브
- **사운드**: Lo-fi Synthwave, 기계 구동음, 전자 노이즈 FX

## 🎮 코어 게임 루프

한 번의 출항은 **보트 위 캐스팅 → 릴 감기 → (조건 충족 시) 직접 잠수 → 부상 및 정산** 순서로 진행된다.

```
① 캐스팅 (Cast)      →  ② 릴 감기 (Reel-in)   →  ③ 다이빙 (Dive)        →  ④ 정산 (Cash Out)
   수심 게이지 타이밍       스와이프로 포획              가상 스틱으로 유영           결과 화면 + 크레딧 환전
```

| 단계 | 조작법 | 설명 |
|---|---|---|
| ① 캐스팅 | **탭** | 오르내리는 수심 게이지를 원하는 깊이에서 탭으로 정지 |
| ② 릴 감기 | **스와이프** | 올라오는 훅 근처를 지나가는 스크랩·변이 어류를 스와이프로 포획 |
| ③ 다이빙 | **가상 스틱** | 직접 입수해 자유 유영. 산소 게이지 소모, 근접 시 자동 흡착 |
| ④ 정산 | 자동 | 산소 소진 또는 부상 시 결과 화면(수확 총액, 최고 등급 아이템) 표시 |

> ✅ 조작법 3종(탭 · 스와이프 · 가상 스틱)이 각 단계에 자연스럽게 녹아 들어가는 구조.

## 🗺️ 수심대별 수집품

| 수심 구역 | 명칭 | 등장 오브젝트 예시 | 특징 |
|---|---|---|---|
| 0 ~ 50m | 표층 플라스틱 존 | 부유 합성수지, 깨진 네온 간판, 3급 오염 피라미 | 기본 환전용 잡동사니 |
| 50 ~ 150m | 드론 공동묘지 | 구형 감시 드론 코어, 망가진 사이버웨어 의수, 네온 뱀장어 | 가격 대비 부피 큼, 회수 난이도 보통 |
| 150 ~ 300m | 산업 슬러지 해저 | 폭발 화학 드럼통, 메가코프 데이터 칩, 기계 융합형 심해 아귀 | 감전/폭발 위험(감점) 또는 고가치 |
| 300m+ | 심연 금지구역 | 프로토타입 AI 코어, 침몰한 메카 잔해, 전설의 유전자 변이 크라켄 | 희귀 도감 해금, 극고가 보상 |

## 📈 성장 시스템

- **마그넷 장착 용량**: 한 번에 건져 올릴 수 있는 오브젝트 개수 증가
- **와이어 길이**: 도달 가능한 최대 수심 확장 (신규 구역 해금)
- **스크랩 정제기**: 오프라인 시에도 소량 자원이 지속 환전되는 패시브 수익
- **노마드 장비 튜닝**:
  - EMP 펄스 — 회수 중 반경 내 스크랩 일괄 흡착
  - 침식 방지 코팅 — 폐수 독성 대미지 무효화, 심층 도달 지원
